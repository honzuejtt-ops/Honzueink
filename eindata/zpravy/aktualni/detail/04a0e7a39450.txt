AI Agent Skills
Komunitní open-source adresář s 8 900+ skills pro Claude, Codex a AI agenty – určený vývojářům a týmům.
O nástroji
AI Agent Skills je nezávislý, komunitně provozovaný adresář a marketplace pro objevování skills, Claude code šablon a pluginů určených pro Claude, Codex a další AI agenty. Katalog aktuálně eviduje 8 942 kurátorovaných skills od 1 046 GitHub maintainerů a snapshot adresáře se aktualizuje každou hodinu. Za posledních 7 dní přibylo 700 nových releases. Skills lze procházet podle kategorií – například prompt engineering, výzkum, browser a web, psaní, design a UI, generování kódu, integrace, produktivita nebo marketing. Každá položka odkazuje na zdrojový repozitář včetně kódu, licence a commitů; do adresáře se skill dostane až po automatizovaných quality checks. Instalace probíhá zpravidla jediným příkazem na příkazovém řádku. Projekt je označen jako open-source a není affiliován s Anthropic ani OpenAI. Bezplatná verze ani placené plány nejsou na webu uvedeny, stejně tak není zmíněno API.
