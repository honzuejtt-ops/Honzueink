V předchozí trojici článků [1] [2] [3] jsme si popsali prakticky všechny důležité koncepty WebGL a OpenGL ES (zbývá ještě popsat texturování). Nyní je tedy ideální čas pro to, abychom si vykreslili první skutečnou 3D scénu.
Začneme jednoduchým příkladem – zobrazením krychle reprezentované drátovým modelem (wireframe), tj. dvanácti úsečkami, které tvoří hrany krychle. 3D zobrazení bude realizováno v několika krocích:
- Úprava vertex shaderu tak, aby akceptoval 3D souřadnice vrcholů úseček
- Úprava polí/bufferů s koncovými body úseček: nyní budou obsahovat 3D souřadnice
- Vylepšení vertex shaderu o vynásobení vstupního vektoru transformační maticí
- Výpočet transformační matice umožňující rotaci krychle okolo dvou os
- Úprava transformační matice: přidání výpočtu perspektivy
Vertex shader akceptující souřadnice koncových bodů reprezentované 3D vektorem
Prozatím jsme do vertex shaderu předávali koncové body úseček atd., které byly definovány v 2D ploše, tj. jednalo se o dvojici souřadnic (typ vec2). Vertex shader k těmto dvěma souřadnicím přidal nulovou z-ovou souřadnici a jedničkovou váhu (W):
attribute vec2 position;
attribute vec4 aColor;
varying vec4 vColor;

void main() {
vColor = aColor;
gl_Position = vec4(position, 0, 1);
Nyní budeme muset do shaderu předávat pro každý koncový bod tři souřadnice (typ vec3), ke kterým shader přidá pouze váhu:
attribute vec3 position;
attribute vec4 aColor;
varying vec4 vColor;

void main() {
vColor = aColor;
gl_Position = vec4(position, 1);

Při specifikaci, jaké vrcholy se budou předávat do vertex shaderu, nesmíme zapomenout na to, že druhý parametr musí obsahovat hodnotu 3 a nikoli 2 (dtto pátý parametr):
// seznam předávaný do vertex shaderu
gl.vertexAttribPointer(p,
3,                                // počet prvků v každém atributu
gl.FLOAT,                         // typ prvků
gl.FALSE,                         // data nejsou normalizována
3*Float32Array.BYTES_PER_ELEMENT, // velikost vertexu v bajtech
0                                 // offset
gl.enableVertexAttribArray(p);
