Za poslední rok zdražilo vše od hardwaru po předplatná softwaru. V těžké době vaší peněžence uleví Microsoft. S okamžitou platností zlevnil dvě nejdražší varianty Game Passu. Ultimate, která vás doteď vyšla na 669 korun měsíčně, dle nového ceníku stojí „jen“ 499 korun. Cena PC Game Passu se pak z 369 korun za měsíc mění na 319 korun.
Nové ceny Xbox Game Pass
- Xbox Game Pass Essential - 239 Kč / měsíc
- Xbox Game Pass Premium - 329 Kč / měsíc
- Xbox Game Pass Ultimate -
669 Kč / měsíc -> 499 Kč / měsíc
- PC Game Pass -
369 Kč / měsíc -> 319 Kč / měsíc
Sleva se neobešla bez kompromisů. Nové díly ze série Call of Duty už se neobjeví v předplatném hned v den vydání, což platí pro Game Pass Ultimate i PC Game Pass. Jeho příchod do nabídky mají předplatitelé očekávat zhruba s ročním zpožděním. Letos nás dle spekulací čeká Modern Warfare 4. Podle tohoto plánu se v Game Passu objeví během vánoční sezóny 2027.
Pro aktuální nabídku se nic nemění. Všechny díly ze série, které jsou v Game Passu dostupné, nikam nezmizí. Je ale jasně vidět, jak moc Activision rozhodnutí přihodit Call of Duty do předplatného v den vydání zabolelo. Nejenže se tím v podstatě připravil o část prodejů, zároveň v reakci na nepříliš úspěšný díl přišlo zdražení předplatného na takovou částku, jakou si běžný hráč dokázal ospravedlnit jen těžko.
