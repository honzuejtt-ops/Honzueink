Článek
Truth API za poplatek ve výši až 100 tisíc dolarů (2,1 milionu korun) měsíčně nabízí dřívější přístup k příspěvkům celkem deseti vládních účtů, včetně toho Trumpova. Tato služba byla spuštěna 1. srpna, uvádí agentura Reuters.
Trump se tak snaží využít toho, že jeho příspěvky mají schopnost ovlivnit ceny akcií či ropy, což se stalo velmi viditelným během amerického konfliktu s Íránem. Středeční žaloba proto požaduje, aby federální soud po dobu existence Truth API Bílému domu zakázal vládní oznámení zveřejňovat výhradně na Truth Social.
Text žaloby službu označuje za „hluboce zkorumpovanou“, protože Trump díky ní bude vydělávat na vládních informacích. Truth API podle žaloby rovněž porušuje první dodatek americké ústavy, protože podle té, mají mít k prezidentovým oznámením všichni občané rovný přístup.
Za službou Truth API stojí společnost Trump Media, v níž největší podíl drží právě Trump. Konkrétně vlastní 41,3 procenta společnosti a jeho podíl má hodnotu přibližně 950 milionů dolarů (20 miliard korun). Ředitelem společnosti je Trumpův nejstarší syn Donald Trump Jr.
Mluvčí společnosti Trump Media obvinění, že její služba porušuje ústavu, odmítl a žalobu naopak nazval pokusem o cenzuru amerického prezidenta. „Levicoví aktivisté se nyní snaží zneužít soudy jako zbraň, aby ho cenzurovali,“ řekl konkrétně mluvčí.
Služba Truth API čelí odporu i v Kongresu. Přední demokratičtí senátoři Elizabeth Warrenová a Adam Schiff požadují, aby Komise pro cenné papíry a burzy USA vyšetřila, zda služba za účelem obohacení Wall Streetu, bohatých insiderů a Trumpa samotného nepodrývá integritu finančních trhů.
