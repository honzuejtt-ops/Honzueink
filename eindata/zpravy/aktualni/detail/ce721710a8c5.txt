agent-marketplace
CLI nástroj pro sdílení AI agent zdrojů (skills, commands, subagenty, MCP servery) napříč týmy a vývojářskými nástroji.
O nástroji
Agent Marketplace je command-line nástroj vytvořený inženýry společnosti Adyen, který umožňuje sdílet AI agent resources napříč týmy, repozitáři a různými vývojářskými nástroji. Resource může být skill, command, subagent, hook nebo MCP server – nástroj je čte z registrů (Git repozitářů nebo lokálních složek) či z hostovaných Marketplaces a zapisuje je v nativním formátu pro každý cílený nástroj. Mezi podporované cíle patří Factory Droid, Claude Code, Cursor, Windsurf, Gemini CLI, Devin CLI, Codex a OpenCode. Nástroj je určen zejména pro platform engineering týmy, které spravují sdílené vývojářské nástroje ve firmě – publikují resource jednou místo opakovaného psaní instrukcí pro každý nástroj zvlášť. Ostatní uživatelé pak mohou potřebné resources vyhledávat z terminálu, v interaktivním prohlížeči nebo pomocí příkazu search. CLI nabízí příkazy init, install, sync a status; konfigurace se ukládá do souboru .agents/config.yaml a commituje se spolu s .agents/lock.yaml, takže každý clone získá stejné soubory, a sync --check lze využít v CI ke kontrole driftu. Technicky jde o jediný Go binární soubor pro macOS a Linux bez runtime závislostí. Je to open source projekt vytvořený inženýry Adyen, nejde však o oficiální produkt společnosti. Informace o cenách nejsou v dostupných podkladech uvedeny.
